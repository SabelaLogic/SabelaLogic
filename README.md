# SabelaLogic

A solo software studio run by **Lunga Xhamela** in Bloemfontein, South Africa, since 2024. I build web apps, automations and small tools for clients worldwide.

**Stack:** Next.js, TypeScript, Cloudflare Workers, Supabase, n8n, Paystack integrations, Android (Kotlin), Blender tooling.
